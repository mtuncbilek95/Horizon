

Horizon is a centeralized and modularized game engine. It mainly targets desktop games via DirectX12. Overall flow is based on services which stay in core application's 
life time scope. Games run on sparse-set entity component system with singular lua scripting per entity. 

`PS5 and XBOX support has been marked as W.I.P.`

Engine doesn't have any goal or target. It is a passion project to make a game from scratch with a detailed custom game engine.
